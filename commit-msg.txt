Make the pet insist when a turn ends and nobody is looking

The pet exists for the case where the main window is closed, and until now a turn
ending there only changed its face -- a 132px expression in the corner of a screen
you are using for something else is easy to miss entirely.

A turn ending now raises a notice when, and only when, the main window is hidden.
With it up, the transcript is right there and the face is enough; raising a notice
while someone is already watching is noise. The notice does not fade on its own,
because something that fades is exactly what someone who stepped away would come
back and miss -- opening the bubble clears it, and that is the action it asks for.

One trap worth recording: the visibility check has to use get_window("main"), not
get_webview_window("main"). The latter returns None once the DSH content is
attached as a child webview, for a window that is very much still there, which
would make every turn ending look like the user was away.

Verified in all three directions: no notice with the main window visible, a notice
with it hidden, and a clear when the bubble is opened through the pet's own
handler rather than by invoking the command directly.

Also recorded in the design doc: session switching is implemented as pinning the
pet rather than switching the main window, which is what the design said. The pet
only matters when the main window is closed, and you cannot switch to a session in
a window that is not there; the main window's URL also carries no session id, so
switching would mean driving DSH's own sidebar DOM.
